## 🎯 Project Overview

This project presents a detailed analysis of three key ethical AI tools across different domains:
- **Fairness**: Aequitas framework for algorithmic fairness assessment
- **Transparency**: LIME (Local Interpretable Model-agnostic Explanations) for model interpretability
- **Privacy**: Opacus differential privacy framework

## 🚀 Quick Start

### Option 1: Direct File Access
1. Clone or download the repository
2. Open `index.html` directly in your web browser
3. No additional setup required!

### Option 2: Local Server (Recommended)
1. Navigate to the project directory:
   ```bash
   cd ethical-ai-tool-analysis
   ```

2. Start a local HTTP server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Python 2
   python -m SimpleHTTPServer 8000
   
   # Using Node.js (if you have http-server installed)
   npx http-server -p 8000
   ```

3. Open your browser and visit: `http://localhost:8000`
