# 10-15分钟演示指南 | Presentation Guide (10-15 Minutes)

## 📅 时间分配 | Time Allocation

**总时长：14分钟 | Total Duration: 14 minutes**

| 章节 | 时间 | 关键要点 | Section | Time | Key Points |
|------|------|----------|---------|------|------------|
| 项目概述 | 2分钟 | 团队介绍、课程背景 | Project Overview | 2 min | Team intro, course context |
| 公平性工具 | 3分钟 | Aequitas核心功能 | Fairness Tool | 3 min | Aequitas core features |
| 透明度工具 | 3分钟 | LIME关键特性 | Transparency Tool | 3 min | LIME key features |
| 隐私工具 | 3分钟 | Opacus主要能力 | Privacy Tool | 3 min | Opacus main capabilities |
| 对比总结 | 3分钟 | 三工具比较和建议 | Comparative Summary | 3 min | Tool comparison & recommendations |

## 🎯 演示策略 | Presentation Strategy

### 1. 项目概述 (2分钟)
**重点内容：**
- 快速团队介绍（30秒）
- 课程背景：PHI4005伦理AI（30秒）
- 三个工具领域：公平性、透明度、隐私（1分钟）

**演示技巧：**
- 使用网站导航快速展示结构
- 强调合规性（不使用Microsoft/IBM工具）

### 2. 公平性工具分析 - Aequitas (3分钟)
**核心要点：**
- 工具概述：算法公平性评估（45秒）
- 关键功能：多种公平性指标、可视化报告（1分钟）
- 实际案例：招聘算法偏见检测（1分钟）
- 主要优势：开源、易用、全面（15秒）

**演示重点：**
- 展示工具界面或架构图
- 强调实际应用价值

### 3. 透明度工具分析 - LIME (3分钟)
**核心要点：**
- 工具概述：模型可解释性（45秒）
- 关键功能：局部解释、模型无关（1分钟）
- 实际案例：医疗诊断模型解释（1分钟）
- 主要优势：直观、通用、可靠（15秒）

**演示重点：**
- 展示LIME解释示例
- 强调透明度的重要性

### 4. 隐私工具分析 - Opacus (3分钟)
**核心要点：**
- 工具概述：差分隐私框架（45秒）
- 关键功能：隐私预算、噪声注入（1分钟）
- 实际案例：用户数据保护训练（1分钟）
- 主要优势：PyTorch集成、易用（15秒）

**演示重点：**
- 解释差分隐私概念
- 展示隐私保护效果

### 5. 对比总结 (3分钟)
**核心要点：**
- 三工具对比表快速浏览（1分钟）
- 关键发现和建议（1.5分钟）
- 未来发展方向（30秒）

**演示重点：**
- 使用对比表格
- 总结各工具适用场景

## 🔧 演示控制技巧 | Presentation Control Tips

### 时间管理
- **使用计时器**：每个章节设置提醒
- **预留缓冲**：为Q&A留出1-3分钟
- **关键节点**：5分钟、10分钟时检查进度

### 导航技巧
- **固定导航栏**：快速跳转章节
- **平滑滚动**：避免突兀跳转
- **语言切换**：根据观众需要调整

### 互动要素
- **实时演示**：展示网站功能
- **案例说明**：用具体例子解释概念
- **视觉辅助**：利用网站的图表和对比表

## 🎤 演讲要点 | Speaking Points

### 开场白示例
"今天我们将用14分钟时间为大家展示PHI4005课程的伦理AI工具分析项目。我们团队分析了三个不同领域的工具：公平性、透明度和隐私保护。"

### 过渡语句
- "接下来让我们看看..."
- "这个工具的关键特性是..."
- "从实际应用角度来看..."
- "与前面的工具相比..."

### 结束语示例
"通过这三个工具的分析，我们可以看到伦理AI工具的多样性和重要性。每个工具都有其独特的价值和适用场景。感谢大家的关注，现在开始Q&A环节。"
