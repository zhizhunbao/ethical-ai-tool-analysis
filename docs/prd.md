# PRD — PHI4005 Ethical AI Tool Analysis 静态页面生成规范

## 0. 执行摘要（给 Claude）
你将根据本 PRD 生成 **单页静态网站**（无需构建、可本地双击打开）。  
必须严格遵守 **文件结构、技术与内容约束**，并通过 **验收标准**逐条自检。  
在输出中 **仅返回代码与文件内容**（按本 PRD 的“交付物”格式），不要输出其它解释性文字。  
**所有演示数据（工具、案例、引用文献等）由你自动生成，符合课程要求。**

---

## 1. 目标与范围
- **目标**：生成一个信息完整、易展示、可离线访问的单页静态站点。  
- **范围**：仅静态前端（HTML/CSS/JS）；不使用后端与在线依赖。  
- **非目标**：不接入第三方 UI 框架或构建工具（如 React、Vue、Next.js、Tailwind、Bootstrap 等）。

---

## 2. 硬性约束（Hard Constraints）
1. **供应商限制**：严禁选择或引用 **Microsoft**（Fairlearn, InterpretML 等）与 **IBM**（AI Fairness 360, AI Explainability 360 等）开发的工具。  
2. **最少来源数**：全站引用来源总数 **≥ 6**，并在“References”区列出，同时正文有内联标注 [1]、[2]。  
3. **交互/展示**：页面包含导航栏与章节锚点，支持“逐段演示模式”。  
4. **可离线**：禁止任何 CDN、Web 字体、外链图片或脚本；所有资源本地化。  
5. **合规声明**：页尾附加“工具选择合规声明”。  
6. **可访问性**：语义化 HTML，颜色对比度 ≥ 4.5:1，键盘可导航，图表/图片有 `alt` 文本。  
7. **性能**：首屏 ≤ 200KB（HTML+CSS+JS）。  
8. **学术诚信**：引用真实文献，禁止虚构。  
9. **国际化要求**：页面需提供 **中英文国际化**，默认展示 **英文**，用户可切换到中文。  
10. **数据与代码分离**：  
    - 页面内容（工具信息、案例、引用文献）存放在单独的 JSON 文件中，例如 `src/data.json`。  
    - `index.html` 只负责结构，`main.css` 只负责样式，`main.js` 负责逻辑与加载 JSON 数据。

---

## 3. 目标用户与使用场景
- **目标用户**：课程老师与同学。  
- **使用场景**：演讲时按章节顺序展示，讲解者通过导航或键盘切换内容。

---

## 4. 页面信息架构
1. **Hero / Overview**（项目标题、组员信息、课程信息）  
2. **Agenda**（演示大纲）  
3. **Fairness（工具 A）**  
   - A.1 Tool Overview  
   - A.2 Approach & Workflow  
   - A.3 Strengths  
   - A.4 Limitations  
   - A.5 Real-World Case & Risk Mitigation  
4. **Transparency（工具 B）**  
   - 同上结构（B.1–B.5）  
5. **Privacy（工具 C）**  
   - 同上结构（C.1–C.5）  
6. **Comparative Summary**（三工具对比表）  
7. **References**（≥6 条，编号显示）  
8. **Compliance Note**（合规声明）  
9. **Appendix（可选）**

---

## 5. 技术与文件结构
- **禁止**：打包器/框架/CDN/外链。  
- **必须**：原生 HTML + CSS + JS。  
- **编码**：UTF-8。  

```plaintext
project-root/
├── index.html
└── src/
    ├── main.css
    ├── main.js
    └── data.json
```

## 6. 交互与可用性
- 页面顶部提供固定导航栏，点击可跳转到各个章节。  
- 支持平滑滚动，当前章节在导航中高亮显示。  
- 移动端适配（≤720px），导航栏自动折叠为菜单。  
- 提供语言切换按钮（默认英文，可切换中文）。  

---

## 8. 内容与文献
- References 部分必须包含 **≥6 个正规来源**，并按编号顺序列出。  
- 建议正文使用 `[1]`、`[2]` 形式的文内引用，对应 References。  
- 页尾可附加 **Compliance Note**：  
  *“本展示严格遵守课程要求，未使用 Microsoft 或 IBM 开发的 AI 伦理工具。”*
